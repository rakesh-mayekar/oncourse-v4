# Card sections: where detail opens in a popup vs. elsewhere

Client suggestion: if a card opens a popup with the full information, the card itself should only show
the caps sub-heading (e.g. MEDICAL SCHOOL), the title (e.g. A Pathway into Medicine) and "Learn More".
The description lives only in the popup.

## A. Cards that open a popup (rule applied)

| Page | Section | Cards | Status |
|---|---|---|---|
| Undergraduate | Specialised Guidance for Individual Goals (#additional-services) | Medical School, Athletic Recruitment, Transfer Admissions, Art & Design, Law | Done: card = caps label + title + Learn More; popup = caps label, title, description, logo slots, Book a Consultation |

This is the only card section on the site that has a "Learn More" popup. Master's, MBA and Test Prep have no equivalent section.

## B. Cards with a description but NO popup (not changed: removing the description would remove the only copy)

| Page | Section | Where the detail is | Note |
|---|---|---|---|
| Home | Find the Right Path for You | Whole card links to the programme page | Candidate if client wants shorter cards |
| Home, UG, Master's, MBA | Every Journey / Proven Results story cards | "Read Story" goes to Success Stories | Candidate |
| Undergraduate | A More Personal Approach (4), Journey stages (3) | Inline only | Inline content, no detail page |
| Master's, MBA, Test Prep | USP, Roadmap, Overview categories, Case studies, Why Test Prep | Inline only | Inline content |
| All programmes | Knowledge Centre / Events cards | Download / reserve flow | Different pattern |
| Team, About | Team portraits | One-line intro on hover (desktop) or tap (mobile) | Done separately |
| Careers | Open positions | Apply form | Different pattern |

If the client wants the same "label + title + Learn More" treatment on any section in B, a popup (or link) for the detail has to be added first.
